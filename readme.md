# AI-Isaev — портфолио Дмитрия Исаева

Одностраничное портфолио разработчика автоматизаций для малого бизнеса. Сайт собран без сборщика и сторонних UI-библиотек; публикуется на GitHub Pages.

## Файлы

- `index.html` — содержание, стили и небольшие интерактивные элементы;
- `avatar-hd.jpg` — портрет для главного экрана и блока «Обо мне»;
- `assets/portfolio/` — реальные снимки опубликованных интерфейсов и локальных прототипов;
- `assets/manrope-*.woff2` — локальные подмножества Manrope для латиницы и кириллицы;
- `assets/OFL-Manrope.txt` — лицензия шрифта Manrope, SIL Open Font License;
- `og-card.html`, `og.png` — исходник и превью для социальных сетей.

## Портфолио

На главной странице показаны четыре интерфейса:

1. `lustra-parser` — опубликованный каталог светильников. Снимок показывает актуальный публичный экран: 556 из 561 позиций, данные на странице отмечены обновлением от 25.06.2026. Числа из старого README (13 703 товара) больше не используются.
2. `TelegrammBot-avtoservis` — бот заявок и CRM для автозапчастей. На снимке доска с одной заявкой; VIN и имя клиента скрыты графическим слоем перед публикацией.
3. `Bankrot` — продуктовый прототип сервиса поиска лотов и личного кабинета: каталог, фильтры, карточки объектов, избранное и подборки.
4. `AI-Arkestrator` — интерактивный прототип сценария ассистента встреч: разбор поручения, согласование времени, календарное представление и журнал встреч.

Ещё проекты описаны текстом, без скриншотов интерфейса: AI-конвейер публикаций для VK, Windows-приложение для учёта проектов монтажной компании, внутренний MVP Razbirator, локальная аналитика спроса из сообщений Avito и административное пространство Beauty coworking. Для VK число 145 материалов и две публикации взято из сохранённой заметки от 22.07.2026 и явно датировано.
